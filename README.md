# 🛒 SwiftCart

> 🛍️ Everything you need, Delivered.

SwiftCart is a complete **Flutter-based e-commerce delivery ecosystem** designed to provide a seamless shopping and delivery experience.

The project includes:

- 📱 Customer Shopping App
- 🖥️ Admin Panel
- 🛵 Rider / Delivery App
- 🔥 Firebase Backend
- 📦 Real-time Order Management
- 📍 Delivery Tracking
- ⭐ Product Reviews & Ratings
